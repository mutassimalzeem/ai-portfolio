# Portfolio

Production Next.js portfolio application.

## Commands

```text
npm install
npm run dev
npm run build
```

## Production environment

Set `RESEND_API_KEY` in Vercel to deliver contact messages to `mutassimalshahriar@gmail.com`.
Optionally set `RESEND_FROM_EMAIL` to a verified sender address and `DATABASE_URL` to persist messages with Prisma.
